GLAVNYE API ENDPOINTS:  
-----------------------  
  
1. AVTORIZATSIYA:  
   POST /auth/login  
   Body: {\"login\": \"dean\", \"password\": \"dean123\"}  
  
2. SPRAVOCHNIKI:  
   GET /enums/ - vse perechisleniya  
  
3. CRUD:  
   GET/POST /faculties  
   GET/POST /directions  
   GET/POST /groups  
   GET/POST/PUT/DELETE /students  
  
4. SPETSIALNYE PRIKAZY (kaskadnoe sozdanie):  
   POST /special-orders/enrollment-with-students  
   POST /special-orders/expulsion-with-students  
   POST /special-orders/academic-leave-with-students  
   POST /special-orders/next-course-with-students  
   POST /special-orders/transfer-direction-with-students  
  
5. PECHAT PRIKAZOV:  
   GET /orders/{id}/print - HTML dlya pechati  
  
6. RAZNITSA UCHEBNYKH PLANOV:  
   GET /curriculums/difference/{dir1_id}/{dir2_id}  
  
7. OTChETY:  
   GET /reports/contingent?period_start=...
